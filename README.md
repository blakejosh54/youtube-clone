# YouTube UI Clone

A clone of the YouTube interface focusing on layout, styling, and responsiveness.

## Features
- Responsive video grid layout
- Sidebar navigation
- Header with search bar and icons
- Clean, modern UI inspired by YouTube
- Functional search bar
- Modal video player
- Functional theme change button

## Tech Stack
- HTML
- CSS
- JS
